Who We Are

A one-person, indie studio founded on a few core beliefs — do things well, keep them open, and never take control away from the user.

Simplicity First

Every project starts with one question: can this be simpler? If the answer is yes, we simplify.

Linux Philosophy

Small, focused tools that work together — open, transparent, and built the way free software was meant to be.

Control Your System

Your computer should obey you — not the other way around. No lock-downs, no walls, no deciding-for-you like Windows, macOS, or ChromeOS. You own it.

Built in the Open

Everything is developed publicly on GitHub. Inspect it, learn from it, improve it.
